Database Tables
MySQL / PostgreSQL

            

              
ambulance
id, ambulance_number, latitude, longitude, destination, status, priority, speed, eta, timestamps.

              
traffic_signal
id, signal_code, name, latitude, longitude, current_state, normal_phase, priority_enabled.

              
route
id, ambulance_id, origin, destination, distance, eta, created_at.

              
priority_event
id, ambulance_id, signal_id, action, previous_state, new_state, reason, created_at.

            

          

          
HTTP Validation & Error Strategy
Required meaningful responses

            

              
400 Bad Request
Missing ambulance ID, origin, destination or invalid speed/severity.

              
404 Not Found
Ambulance, route or signal does not exist.

              
409 Conflict
Unsafe signal priority conflict or duplicate active priority.

              
500 Server Error
Unexpected backend failure with a useful message and audit log.

Hackathon Best Feature Set
Prioritize these in your final demo

          
1. Dynamic Green Corridor
Sequentially prioritize only the next relevant traffic signal.

          
2. AI Priority Score
Explainable model based on severity, ETA, distance and signal state.

          
3. Predictive Congestion
Estimate congestion and choose the route that minimizes emergency delay.

          
4. Human-in-the-loop
Operator approves or overrides AI recommendations.

          
5. Safety Conflict Detection
Block risky signal requests and return 409 Conflict.

          
6. Audit + Analytics
Record every change and show time saved, success rate and impact.
